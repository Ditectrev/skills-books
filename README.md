# skills-books

Cursor skill for generating new **Ditectrev Awesome Book & Course** repositories from the HTML, A11Y, and AZ-900 templates.

Skill path: [`.cursor/skills/ditectrev-books/SKILL.md`](.cursor/skills/ditectrev-books/SKILL.md)

New books should use `__extra-resources` (not AZ-900’s misspelled `__extra-resourcers`).
